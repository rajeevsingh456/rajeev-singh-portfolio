## Run
### Backend
```bash
cd backend
npm install
npm start
```
Backend: `http://localhost:5000`

### Frontend
Open `frontend/index.html` directly in Chrome, or serve the folder with a static server.

## Resume
`frontend/Rajeev-Singh-Resume.pdf` is the uploaded resume and is linked from the hero section as **Download Resume**.

## Profile photo
Replace `frontend/assets/profile-photo-placeholder.svg` with a professional image named `profile-photo.jpg`, then update the `<img>` source in `frontend/index.html` if desired.

## Note on client/project details
Only project/client relationships explicitly supplied or present in the resume are presented as specific mappings. Other client entries are shown at a high level to avoid inventing confidential project details.
